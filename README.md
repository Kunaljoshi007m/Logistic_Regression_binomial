# Logistic Regression Analysis GUI

A GUI-based Machine Learning application for performing **Logistic Regression analysis and classification** on compatible numerical CSV datasets.

The application provides an interactive graphical interface for loading a CSV dataset, configuring the train-test split, standardizing numerical features, training a Logistic Regression model, evaluating its performance, and generating multiple data visualizations.

The repository includes `heart.csv` as an example dataset, but the application can load other compatible numerical CSV datasets through the GUI.

---

## 📌 Project Overview

This project provides an interactive environment for experimenting with Logistic Regression and dataset analysis.

The application supports:

- CSV dataset loading
- Dynamic column detection
- Train-test splitting
- Feature standardization
- Logistic Regression
- Model prediction
- Accuracy evaluation
- Precision evaluation
- Recall evaluation
- F1-score evaluation
- Confusion Matrix
- Classification Report
- ROC Curve
- AUC Score
- Correlation Heatmap
- Bar Plot
- Boxplot
- Bar Chart
- Interactive graphical interface
